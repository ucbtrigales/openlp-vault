OpenLP Vault

OpenLP Vault creates complete backups of OpenLP data and lets you store, restore, and delete them using Google Drive.

View on GitHub Read the usage guide

Features

Local and Google Drive backups

Create local backups or upload them to a Google Drive folder.

Restore and deletion

List, download, restore, and delete backups stored in Drive.

Desktop interface and CLI

Use the desktop interface or the commands available in the terminal.

Google Drive authentication

Uses OAuth and reuses the authorization token stored locally.

Integrity

Includes SHA-256 integrity and versioning utilities.

Basic usage

Desktop interface

openlp-vault-gui

On first launch, Settings opens if no reusable OAuth authorization exists. Provide:

  • The path to credentials.json.
  • The OpenLP data directory.
  • The Google Drive folder name.

Command-line interface

openlp-vault --help

Available commands are auth, backup, restore, and delete.
